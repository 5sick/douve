개인정보처리방침

시행일: 2026년 10월 5일

이 Douve는 운영자가 자신의 서버를 관리하기 위해 운영하는 비공개 서비스입니다. 로그인은 운영자가 미리 허용한 계정만 가능합니다.

수집하는 정보

  • Google 계정 이메일 주소 — Google 로그인 시 본인 확인과 허용 여부 판단에만 사용합니다. Google의 액세스 토큰·갱신 토큰은 저장하지 않으며, 이메일 외의 Google 계정 정보(이름, 사진, 연락처 등)는 요청하지 않습니다.
  • 패스키 공개키 — 패스키 로그인 확인용입니다. 지문·얼굴 등 생체 정보는 기기 밖으로 나오지 않으며 Douve에 전달되지 않습니다.
  • 로그인 세션 정보 — 접속 IP 주소, 브라우저 정보(User-Agent), 로그인 시각.
  • 보안 기록 — 로그인 성공·실패, 패스키 등록·삭제 등의 이벤트와 시각, IP 주소.

이용 목적

로그인 인증, 로그인된 기기 관리, 무단 접근 탐지와 보안 사고 대응에만 사용합니다. 광고·분석·마케팅에는 사용하지 않습니다.

보관과 제3자 제공

모든 정보는 운영자가 관리하는 서버에만 저장되며 제3자에게 제공하거나 판매하지 않습니다. 세션 정보는 만료(최대 90일) 시 삭제되고, 보안 기록은 보안 점검을 위해 보관합니다.

Privacy policy

Effective: October 5, 2026

This Douve is a private service run by its operator to manage their own servers. Only accounts the operator has allowed can sign in.

What is collected

  • Google account email address — used only to identify you and check whether you're allowed when you sign in with Google. Google access and refresh tokens are not stored, and no other Google account data (name, photo, contacts, …) is requested.
  • Passkey public keys — used to verify passkey sign-ins. Biometric data such as fingerprints or faces never leaves your device and is never sent to Douve.
  • Sign-in session data — IP address, browser information (User-Agent) and sign-in time.
  • Security records — events such as successful and failed sign-ins and passkey additions or removals, with time and IP address.

How it is used

Only for authentication, managing signed-in devices, detecting unauthorized access and responding to security incidents. Never for advertising, analytics or marketing.

Storage and third parties

All data is stored only on servers the operator manages and is never shared with or sold to third parties. Session data is deleted when it expires (at most 90 days); security records are kept for security reviews.
